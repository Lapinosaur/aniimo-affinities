## Aniimo Affinities v0.4.3

- Click a view button to swap its content into the main window. The button takes the previous view's icon.
- Hold the mouse button or Space for 0.9 seconds to open that view in a separate window. Releasing an already-started hold does not trigger a short click.
- Existing matrix and radar keyboard shortcuts still open separate windows.
- Radar legends now show **Attack** in amber and **Defense** in blue, in both combined and separate layouts. Detailed explanations remain available in tooltips.
- Updated tutorial instructions and button tooltips to match the new controls.

Download **AniimoAffinities.exe** and run it directly. Windows x64, .NET Framework 4.x; no installation required. This executable remains unsigned. **SHA256SUMS.txt** is provided for integrity verification.

User preferences and the tutorial opt-out remain stored separately from the executable.
