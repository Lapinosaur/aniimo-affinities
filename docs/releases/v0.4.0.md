## Aniimo Affinities v0.4.0

- Atomic update replacement, exclusive installation lock and startup confirmation with rollback.
- Recovery journal for interrupted installations and cleanup of stale installer files.
- Download progress, cancellation, and a per-version skip option.
- Tutorial previews and dimming follow live appearance changes.
- Preserved tutorial opt-out and preferences across updates, covered by regression tests.
- Local storage cleanup preserves settings, prepared updates and executable backups.
- Copyable diagnostics without usernames, executable paths, tokens or exception messages.
- Window zoom adapts to the available desktop area.
- Version metadata comes from package.json; releases are built and tested by GitHub Actions.

Windows x64, .NET Framework 4.x. Download AniimoAffinities.exe; no installation needed.
The executable is unsigned. SHA256SUMS.txt is provided for integrity verification.

The enhanced installer applies when updating *from* this version onward. Older versions use their existing updater for the transition to v0.4.0.
