## Affinisaur v0.7.0

Build a more complete team, understand each suggestion and compare your allies at a glance.

### Complementary team suggestions

- Empty ally slots offer mono- or dual-type proposals that account for earlier suggested slots, instead of repeating the same combination everywhere.
- **Suggested coverage** improves general type coverage. **Suggested counter** responds to known opposing members. Once coverage is complete, suggestions keep adding backup answers with diminishing returns.
- Gray type icons distinguish proposals from applied members. Use the sparkle button on a card, or + / Ctrl+Enter in the editor, to apply a proposal; the remaining suggestions then refresh.
- Graphical explanations show opposing type icons, swords and shields, damage multipliers and answer counts before/after. Applied allies and earlier unapplied proposals are explicitly distinguished.

### Compare allies and investigate threats

- Check ally cards to add a colored trace per member to the main Attack and Defense radars. Each card carries its matching color legend; both radars share a dynamic scale.
- Threat reports cover single types, grouped dual types and members, with element icons, readable damage values and individual matchup details.
- Attack and Defense retain their shared orange/blue identities. Suggested cards, comparison controls and report tooltips use the application's common visual components.

### Overlay and guided discovery

- Locked overlays use native frosted surfaces while text and icons stay sharp and the surrounding background remains transparent. Movement and unlocking remain available; unavailable ally actions are hidden.
- Native glass-window lifecycle and placement have been reworked, including the circular ownership exception and unnecessary allocations. Glass resources are prepared after startup; first-lock timing still depends on readiness and the host system.
- The team tutorial now explains suggestions, projected teams, comparison checkboxes and locked controls. Returning users get a short **What's new** tour once, with Skip/Esc and replay from Help. Existing tutorial completion history is retained.
- Shared calculations and rendering paths have been consolidated, with parity, lifecycle and interaction regression coverage.

### Compatibility and limits

- Portable Windows x64 / .NET Framework application; existing preference locations and executable update paths remain supported. The publication workflow provides Affinisaur.exe, an identical AniimoAffinities.exe compatibility asset and SHA256SUMS.txt.
- Suggestions use known elemental matchups only, not species, moves or combat statistics. Projected suggestions are not applied automatically. Ally comparison checks last for the current session and affect the main radars only.
- The build is unsigned. Actual Windows 10 visual acceptance, the full mixed-DPI matrix, screen-reader review and OBS/capture testing remain outstanding. Native composition has a capability fallback; this is not a claim that every supported environment was manually tested.

### Validation

Formatting, analyzer/compiler checks and all isolated regression groups pass locally. Resource probes retain no forms after 60 form lifecycles, with stable GDI and USER counts. Current screenshots have been visually checked. The publication workflow rebuilds and tests the release commit before uploading its executable and checksums.
