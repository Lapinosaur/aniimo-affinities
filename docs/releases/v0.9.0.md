# Affinisaur v0.9.0

## A smoother first launch

- A short welcome flow helps you choose your language, theme and whether to start a guided tour.
- Search languages with **Ctrl+K**. Inline gray suggestions complete with **Tab**; **Enter** confirms the highlighted result. Clearing your search restores the default choice.
- Navigate choices with **Up / Down**, jump to either end with **Page Up / Page Down**, and go back with **Backspace** outside the search field.
- Theme choices support **1 / 2 / 3**; the tour choice supports **1 / 2**. Shortcut badges follow your display preference and no longer shift button labels.
- Visual previews explain what happens to radar and table windows when you minimize the main window.

## Your language, offline

- 30 interface languages are embedded in the portable app, including French, German, Spanish, Italian and Portuguese.
- Compressed language resources keep the portable executable around 1.40 MB, with all languages still available offline.
- Change language later in **Settings > Display > Language** with **Apply and restart**. Your team and other settings are preserved.
- Translations are in **beta**. Some phrasing and longer labels still need native-speaker review. User-entered names and external release notes are not automatically translated.

## Windows that work beside your game

- Radar, table and suggestion windows can remain visible when the main window is minimized; this is enabled by default and configurable.
- Content windows have independent minimize and pin/lock controls.
- Ctrl+wheel targets the hovered/focused content window and applies a temporary local scale. Display settings still synchronize all windows.
- Closing the main app from its taskbar preview closes its child windows too.

## Support, updates and reliability

- **F11** opens or refocuses Support throughout the app, with community and project links.
- A confirmed factory reset backs up the profile before returning to first-launch defaults.
- Update checks run at startup. Release notes render Markdown headings, lists and tables; you can defer an update or skip one version.
- Fixed resource retention in window/control callbacks and improved cleanup of timers, bubbles, downloads and glass surfaces.
- Tests now run in 11 isolated batteries, with independent work in parallel and exclusive desktop access for interactive tests.

Existing users receive a short, skippable **What's new** tour for this version. Existing team data, settings and other tutorial completion records are preserved. New users get the welcome setup.
