## Affinisaur v0.6.0

**[Download Affinisaur.exe](https://github.com/Lapinosaur/aniimo-affinities/releases/download/v0.6.0/Affinisaur.exe)** — the recommended portable Windows x64 executable. No installer is required.

### What's changed

- The public executable is now **Affinisaur.exe**. Existing update clients remain supported through an identical legacy asset.
- Help & Tutorial now separates tutorials from technical support. Start, resume or replay individual tutorials; completion checks are recorded automatically. A team-planning tutorial explains known opponents, previews, selection and panel placement.
- Buttons share clearer keyboard focus, selected, disabled and busy states. Team cards use a continuous focus outline instead of the old dotted rectangle. Tooltips also work on keyboard focus, and F6 enters a team row's element controls.
- Long-running update checks, downloads, restart preparation and folder/link operations show loading feedback and prevent duplicate activation.
- The update window lists newer stable versions and their release notes, with keyboard scrolling and an explicit notice if history is incomplete.
- Additional accessible descriptions expose matchup data. Regression coverage checks input cancellation, disabled actions, tutorial progress and update compatibility.

### Update compatibility

Use **Affinisaur.exe** for a new download. **AniimoAffinities.exe** is the exact same binary, retained only for older updaters that require that asset name. **SHA256SUMS.txt** covers both filenames.

An existing installation updates in place, keeping its chosen executable filename and path. It is not forcibly renamed, so existing shortcuts continue to work. Preferences remain in `%LOCALAPPDATA%/AniimoAffinities`; no manual settings migration is needed.

Existing paused tutorial sessions remain resumable. The older tutorial file did not reliably record completion per section, so historical completion is not guessed; new completions are recorded individually.

### Validation and status

Built and tested on Windows using the portable .NET Framework toolchain, with formatting, compiler/analyzer checks and isolated regression groups. Requires Windows x64 and .NET Framework 4.x.

This release is **unsigned**; the SignPath application is pending review. Manual Narrator/NVDA and all mixed-DPI configurations have not been fully validated.
