## Affinisaur v0.5.0

**Aniimo Affinities is now Affinisaur**, the unofficial Aniimo companion by Lapinosaur.

- Plan two teams of six, compare known elemental matchups, preview a member on hover and click to keep a distinct selection.
- Position the team panel on either side, above or below the main view. Coordinated transitions and a right-aligned caption improve layout changes, including repeated clicks.
- Replay selected tutorial sections and resume an unfinished tour. Find Discord support, diagnostics and local storage together in Tutorial & Help.
- Get clearer shortcut capture, held-key feedback and conflict choices to swap bindings or unbind the other action.
- Updated platform icons, support links, folder/copy feedback and an offline Legal & Privacy page maintained in Markdown.
- Added focused code analyzers, restricted SVG XML parsing and isolated parallel regression groups, keeping interactive UI tests sequential.

### Compatibility

Existing preferences and the tutorial opt-out are preserved in `%LOCALAPPDATA%/AniimoAffinities`. The repository URL and release asset **AniimoAffinities.exe** retain their technical names so existing updates continue to work. The displayed product name is Affinisaur.

Download **AniimoAffinities.exe** and run it directly on Windows x64 with .NET Framework 4.x. No installer is required. **SHA256SUMS.txt** verifies file integrity. This release is **unsigned**; the SignPath application is awaiting review.

Mixed-DPI, capture-software and all Windows hardware combinations have not been fully validated; this remains a pre-1.0 release.
