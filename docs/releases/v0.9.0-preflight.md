# v0.9.0 publication preparation

Prepared on 2026-11-04. This document does not record a published release.

## Scope

Portable Windows application: first-launch setup, 30 embedded beta languages, keyboard navigation and inline search completion, independent content windows, F11 support, factory reset, Markdown update notes and resource cleanup. The v0.9 news marker is separate from v0.8 and resets only the news section's completion.

## Verified locally

- Formatting, analyzers, architecture and UTF-8 checks pass; runtime files remain below the project limit.
- All 11 regression batteries pass, with separate preference directories and exclusive desktop access for UI tests.
- Catalog coverage and shortcut tokens are checked for all 30 languages. Selected English/French flows were visually inspected; this is not a human review of every translation.
- Existing-profile detection, session persistence, news-tour opt-out/checkpoints, language persistence, staged onboarding settings, update installation/recovery and reset backup are covered by isolated regression fixtures.
- The keyboard tests exercise Enter from focused controls, provisional language selection, Tab completion, Ctrl+K, arrow wrapping and Page Up/Down.
- Six Python tests cover the release-announcement scripts. No real announcement was sent during preparation.
- New English documentation captures cover language search, comfort options, Display, Support and the current news tour. French comfort/news previews were checked separately.
- Distribution-channel planning copy has been removed from the app's current update tutorial and embedded interface strings.

## Before publication

- Review the branch/PR and require the Windows GitHub check to pass on the final commit.
- Native-speaker review remains advisable; keep translations explicitly marked beta.
- A real installed 0.8.2-to-0.9.0 update on an external Windows machine, mixed-DPI hardware and capture software is not claimed here. The automated fixtures exercise those storage/update paths without changing the user's real profile.
- Publishing and the resulting Discord delivery are separate actions. Run the stable release workflow only when publication is requested; verify its announcement job afterward.

No user profile was reset to prepare this release.
