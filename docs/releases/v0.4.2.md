## Aniimo Affinities v0.4.2

- After a verified update download, **Restart now** starts the installer, closes the current app and reopens the updated version.
- **Restart later** keeps the prepared update for the next launch.
- If the installer cannot start, the current app stays open and displays an error.
- Includes the pinned-content transparency fixes and update reminder choices from v0.4.1.

The new restart button is available in this build's updater. Updating from the published v0.4.1 still uses that version's existing interface; restart it manually after downloading. The new button can then be used for a subsequent update.

Download **AniimoAffinities.exe** and run it directly. Windows x64, .NET Framework 4.x; no installation required. This executable remains unsigned. **SHA256SUMS.txt** is provided for integrity verification.

User preferences and the tutorial opt-out remain stored separately from the executable.
