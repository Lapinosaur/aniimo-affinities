# Tutorial review

Completion checks are status indicators, not replay selectors. A section is completed only after advancing past its final content step. Each section has Play, Resume or Replay; the page groups learning tasks separately from workspace configuration and technical support. Global resume retains the interrupted tour; individual resume retains each section checkpoint.

| Tutorial | Decision | Purpose / changes |
| --- | --- | --- |
| Types & affinities | Keep, clarify | Foundation: Main/Sub, temporary preview, attack versus received damage and multipliers. |
| Effectiveness matrix | Keep | Distinct row/column reading task and combined defenders; not redundant with the basic affinity view. |
| Affinity radar & views | Improve | Explain when radar or matrix is useful; replace the repeated click/hold-only step with view choice and comparison. |
| Team planning | Add | Previously absent despite selection/preview, unknown-data rules and panel placement being non-obvious. Three focused steps. |
| Pin & locked overlay | Keep | Explains click-through lock and deliberately held resize controls. Safety-relevant behavior deserves its own short tour. |
| Keyboard shortcuts | Improve | Include safe held-key testing outside capture and conflict resolution, not only assignment. |
| Display & appearance | Keep | Preview/apply/15-second rollback needs an explanation; theme and persistence remain useful. |

No entire tutorial was removed: each addresses a distinct task. Redundant explanation was replaced rather than adding another general introduction. Support, diagnostics and storage live on a separate Support tab.

Progress format tour-v2 stores completed sections, started sections and individual checkpoints. Legacy tour-v1 pending sessions retain their selected sections and current step. Its ambiguous done state cannot prove which sections were completed, so migration does not fabricate completion checks. Newly completed sections are checked automatically. Startup offers unfinished sections only; the startup preference remains separate.
